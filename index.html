Descripción
En el polo sur de la Luna el Sol apenas roza el horizonte y la Tierra aparece y desaparece detrás del relieve. Una misión necesita las dos cosas: luz para los paneles y la Tierra a la vista para comunicarse. SELENE compara sitios y fechas de alunizaje y muestra dónde están el Sol y la Tierra sobre el horizonte real de cada sitio, con ranking de sitios, mapa de calor de iluminación, la Luna en 3D y un informe imprimible.

Escaneo IP

Ver el repo↗
Contexto
Redes de Datos · ITSP
Equipo
3 estudiantes
Entrega
14/07/2026
Stack
Java · ExecutorService · ping y arp nativos · com.sun.net.httpserver · bash
Repositorio
github.com/lucioooofacc/EscaneoIP
Descripción
Un escáner que recibe una red en notación CIDR, hace ping a cada dirección en paralelo (hasta 100 hilos, 1 s de timeout) y cruza el resultado con la tabla ARP para mostrar IP, MAC y estado. Tiene un modo web con POST /api/escanear y detecta si corre dentro de Flatpak para ejecutar los comandos en el sistema anfitrión.
$ ./ejecutar.sh
