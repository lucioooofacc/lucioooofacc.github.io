Escaneo IP

Ver proyectoCerrar
Contexto
Redes de Datos · ITSP
Equipo
3 estudiantes
Entrega
14/07/2026
Stack
Java · ExecutorService · ping y arp nativos · com.sun.net.httpserver · bash
Descripción
Un escáner que recibe una red en notación CIDR, hace ping a cada dirección en paralelo (hasta 100 hilos, 1 s de timeout) y cruza el resultado con la tabla ARP para mostrar IP, MAC y estado. Tiene un modo web con POST /api/escanear y detecta si corre dentro de Flatpak para ejecutar los comandos en el sistema anfitrión.
$ ./ejecutar.sh
